# Python Data Science + Flask

A beginner-friendly project combining Python, NumPy, Pandas, Matplotlib and Flask.

## Features
- Student CSV data analysis
- Pandas data processing
- NumPy average calculation
- Grade calculation
- Matplotlib performance graph
- Flask web dashboard
- JSON REST endpoint

## Run

    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

Open http://127.0.0.1:5000

API: http://127.0.0.1:5000/api/students
